# Image Generation with Stable Diffusion

## Description
This project uses the Stable Diffusion pre-trained model to generate images from text prompts using Generative AI techniques.

## Features
- Text-to-image generation
- Uses Stable Diffusion v1.5
- Generates unique AI-created images
- Supports custom prompts

## Technologies Used
- Python
- Google Colab
- Diffusers
- PyTorch
- Stable Diffusion

## How It Works
The user provides a text prompt, and the Stable Diffusion model generates an image corresponding to the description.

## Sample Prompt
A modern smart city powered by artificial intelligence

## Output
AI-generated image based on the provided text prompt.
